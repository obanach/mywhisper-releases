# MyWhisper — wydania

Publiczny kanał wydań aplikacji **MyWhisper** (natywne dyktowanie dla macOS 14+).
Kod źródłowy rozwijany jest w prywatnym repozytorium.

## Pobieranie

Najnowsza wersja: zakładka **Releases** → plik `MyWhisper-x.x.zip`.
Instrukcja instalacji (Gatekeeper, onboarding, klucz API): plik `INSTALACJA.md` dołączany do wydań.

## Aktualizacje

Aplikacja sama sprawdza ten kanał przy uruchomieniu (Sparkle, plik `appcast.xml`)
i proponuje instalację nowej wersji jednym kliknięciem. Ręcznie: ikona MyWhisper
w pasku menu → „Sprawdź aktualizacje…".
